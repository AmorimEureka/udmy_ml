

# Projeto  Inicial de estudos Machine Learn

**Configuração do Ambiente**

- Pyenv
    - Definir versão Python

<br>

- Instalação | Configuração | Ativação do Ambiente Virtual:
    ``` sh
    python3 -m venv .venv
    ```

    ``` sh
    source ./.venv/bin/activate
    ```
<br>

- Criar requirements das dependencias do projeto :
    ``` sh
    pip freeze >> requirements.txt
    ```

<br>

- Instalação dos pacotes básicos:
    ``` sh
    pip install pandas scikit-learn jupyter matplotlib seaborn
    ```

<br>
